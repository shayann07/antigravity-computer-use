# Code of conduct

This project is a place to build something useful together. Everyone taking
part, in issues, pull requests, discussions or anywhere else the project is
represented, is expected to:

- **Be respectful.** Criticise code and ideas, never people. No harassment,
  insults, slurs, or unwelcome sexual attention.
- **Assume good faith.** Ask before you assume. Many contributors are new to
  desktop automation or writing in English.
- **Protect privacy.** Don't post other people's personal information,
  screenshots or recordings without their consent. Redact your own before
  sharing.
- **Stay on topic.** Keep threads about the project. Don't spam or promote
  unrelated work.

## Enforcement
The maintainer may edit or remove comments, close threads, and block anyone
who breaks these rules, for a time or permanently. Report problems privately to
the maintainer through the contact on their
[GitHub profile](https://github.com/shayann07), or with
[private vulnerability reporting](https://github.com/shayann07/antigravity-computer-use/security/advisories/new)
if it is sensitive. Reports are kept confidential.
